# Submission checklist

## Local release

- [x] Databricks App deployed and running in the Free Edition workspace.
- [x] Genie Agent is connected to the app and drives the investigation flow.
- [x] Live Genie, SQL, smoke, soak, build and release checks recorded.
- [x] Narrated demo generated and technically verified.
- [x] Final package and SHA-256 manifest generated.
- [x] Final app URL and deployment identity recorded in `release-report/MDL-8/`.

## External handoff

- [ ] Review the narrated video manually.
- [ ] Publish the project story in Databricks Community Articles.
- [ ] Include architecture/data flow and Genie question examples.
- [ ] Publish the demo video and replace its placeholder in the article.
- [ ] Publish the technical deep dive, or remove that link from the article.
- [ ] Grant reviewers access to the Databricks App/workspace if required.
- [ ] Submit the official challenge form and record the submission ID.

Do not invent URLs or a submission ID in repository evidence.
