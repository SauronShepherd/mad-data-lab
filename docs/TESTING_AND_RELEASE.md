# Testing and release

Local release evidence is generated by `scripts/release_candidate.py`. Required checks include Python contracts, canonical data/property validation, security, frontend contract, OpenAPI, typecheck, browser, accessibility, visual/assets, chaos, and soak gates.

The current local suite has passed the Python and browser matrices. SHA-bound evidence is written under `release-report/`; live Genie evaluation, deployed smoke, deployed soak, and human approvals must be refreshed after the final source SHA is frozen. GitHub Actions is intentionally outside this local acceptance scope.

No stale live PASS artifact is accepted as proof of a new source identity.
